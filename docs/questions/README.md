# Questions en attente de réponse

Les décisions non évidentes sont consignées ici plutôt que posées en conversation.
Organisation : `docs/questions/<catégorie>/<sujet>.md` (ex. `identite/`, `modules/`, `donnees/`, `design/`, `tests/`).

## Gabarit d'un fichier

- **Question** : formulation précise.
- **Contexte** : pourquoi elle se pose, avec preuves (chemin:ligne).
- **Options** : avantages et inconvénients.
- **Recommandation vérifiée** : choix retenu pour avancer, avec la vérification effectuée.
- **État** : En attente de réponse / Répondue / Appliquée.

Le travail continue en suivant la recommandation ; la réponse de l'utilisateur peut la corriger plus tard.
